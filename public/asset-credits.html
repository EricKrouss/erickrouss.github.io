Windows 98 interface graphics

The desktop, program and taskbar icons are archived Windows graphics from Alex Meub’s Windows 98 Icon Viewer. The original filenames are preserved in /assets/win98/.

The Windows flag (start.png) and Windows 98 vertical Start-menu bitmap (start-menu-side.png) are sourced from 98.js, Isaiah Odhner’s Windows 98 recreation. Windows graphics and trademarks belong to Microsoft. The archive’s availability is not a claim that the graphics are public domain, and this personal site is not affiliated with Microsoft.

Original Windows 98 title bars and controls

The normal minimize, maximize and close buttons are unchanged 16×14 bitmap crops from GUIdebook’s original Windows 98 Notepad screenshot. Its active caption gradient and the inactive gradient from the Windows 98 SE desktop capture are included as bitmap strips. Desktop metrics match the capture: 18-pixel title bars, four-pixel window frames and two pixels before Close. Phone controls use exact 2× pixel scaling.

The Restore glyph is rasterized from Microsoft’s original Marlett 1.00, extracted from WIN98_49.CAB in an archived Windows 98 installation. The same raster settings match all three captured control glyphs pixel-for-pixel. Microsoft documents Marlett’s use and the Windows 98 version. Pressed states use those same glyph pixels with the native one-pixel offset. The live titles and behavior are implemented in HTML/CSS and React; the graphics remain Microsoft’s. The Marlett font file and Windows installation archive are not distributed by this site.

Startup screens and original sound

The unchanged Windows 98 startup bitmap is from GUIdebook’s Windows 98 capture. Classic displays use this capture; widescreen displays use MalekMasoud’s 16:9 adaptation, hosted locally from its public 1192×670 JPEG preview. This is a fan adaptation of Microsoft’s artwork, not an original widescreen Windows 98 asset. The poster fills landscape viewports; portrait phones retain the full logo against a matching blue background. The original The Microsoft Sound.wav, Quick Launch icons, and speaker icon are preserved by 98.js. This is the 7.86-second startup recording, not the first-run welcome music. Sound plays only after choosing Power on. Skip startup remains silent. These original Microsoft assets are credited here; their availability in an archive does not place them in the public domain.

Interface text font

Windows 98’s default UI typeface was MS Sans Serif, as documented by Microsoft. The desktop shell uses regular and bold MS W98 UI, a browser-compatible conversion of that original bitmap typeface by Lev Leontev and martyr, based on Microsoft’s font. The publisher’s credits are included locally. The original Windows FON format cannot be loaded directly by browsers; scaling and browser text rendering can differ from Windows 98’s native rasterizer. This is not the later Microsoft Sans Serif outline replacement.

Old YouTube icon

The YouTube player uses the original 2005–2009 YouTube favicon preserved on Wikimedia Commons, which cites a 2005 archive of YouTube.com. The 16×16 bitmap is unchanged and enlarged with nearest-neighbor rendering. YouTube remains a trademark of Google.

Internet Explorer 6 and the 2007 watch page

IE6 toolbar bitmaps are preserved Microsoft graphics from ShizukuIchi’s winXP asset archive. The chrome follows Microsoft’s IE6 toolbar reference.

The local YouTube window uses Eric’s HTML5 player, its original assets and bundled video. The page layout, navigation graphics, stars and comment voting icons follow the August 24, 2007 Numa Numa watch-page archive. Comments are fictional and votes/replies are stored only in the visitor’s browser. The page retains period Arial. YouTube artwork belongs to Google; video rights remain with their owners.

Windows 98 MS-DOS Prompt

The console icon and toolbar controls are original crops from GUIdebook’s Windows 98 command-prompt capture. The console’s 6×8 and 8×12 fonts convert the original Microsoft DOSAPP.FON bitmap glyphs into browser-compatible WOFF2. The Windows cabinet and FON file are not bundled.

Classic Minecraft launcher icon

The original 32×32 grass-block favicon used by the old Java launcher is preserved in mclaunch. The same bitmap is hosted by Minecraft Oldschool Edition; the files are byte-for-byte identical. A 2011 launcher installation script documents using Minecraft.net’s favicon as the desktop launcher icon. The downloaded bitmap is included unchanged as minecraft-launcher.png. Minecraft graphics belong to Mojang/Microsoft.
